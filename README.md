# マシュとマロ 〜まよなかの おしごとパズル〜（体験版）

おなじ色のマシュマロを そろえて、マロくんに たべさせる 音楽パズルです。

**▶ あそぶ: https://mukkii-game.github.io/marshmallow-build-demo/**

- 2×2のマシュマロを積んで、同色2×2の正方形をつくる
- 拍に合わせて流れるビルドバーが、まとめて回収してくれる
- 食べたプログラマーの「ノリ」が上がると、マッハタイムで仕事が爆速に！
- 夜明けまでにαビルドを完成させよう

| 操作 | キーボード | タッチ |
|------|-----------|--------|
| 移動 | ← → | ◀▶ / 左右ドラッグ |
| 回転 | ↑ / Z / X | ⟳ / タップ |
| ソフトドロップ | ↓ | ▼長押し |
| ハードドロップ | Space | ⤓ / 下フリック |
| ポーズ | P / Esc | ⏸ |

音が出ます🔊（Mキーでミュート）
